# NumDeck
hieeee!!! i (me and ChatGPT) made this simple python script that turns your dumahh numpad into something useful, a stream deck!<br><br>
this script only runs when numlock is turned off. that way, you can still use your numpad to enter numbers when it's on.<br><br>
only when it's off it's YOUR VERY OWN PERSONAL STREAM DECK FOR LITERALLY ZERO EXTRA RUPEES!!!!<br><br>
ngl i stole the idea from an instagram reel that recommended an already existing app for the same purpose.<br><br>
with the best logo ever.<br><br>
it runs silently in your system tray too!

(unfortunately this is windows-only)

## Instructions
have the csv file (make sure to name it `config.csv`) in the same directory as your executable.

to open files, use this in the middle column of the csv:

`open:{full file address}`

configure the csv file as you wish. the defaults are:

| Key | Action |
|-----|--------|
| 5 | Play/Pause |
| 4 | Previous Track |
| 6 | Next Track |
| + | Volume Up |
| ENTER | Volume Down |
| 9 | Opens a video on my desktop |
| - | Mute |

ideally, have the executable somewhere else, and just have a shortcut of it on your desktop.

when you edit the .csv file, make sure to restart the app.

have fun, and hit me up on my socials to talk about the program! 🌸
